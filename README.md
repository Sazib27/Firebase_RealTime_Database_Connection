\# Restaurant Food Delivery App



Android app using Firebase Realtime Database and Jetpack Compose.



\## Features

\- Add products (name, price, category)

\- View list of products

\- Firebase Realtime Database backend



\## Setup

1\. Add your `google-services.json` to `app/` folder

2\. Set database rules to `{ ".read": true, ".write": true }` for testing



\## Tech Stack

\- Kotlin

\- Jetpack Compose

\- Firebase Realtime Database
